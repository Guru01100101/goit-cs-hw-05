# goit-cs-hw-05

GoIT University: Computer Science & Their Fundamentals, домашнє завдання 5
(асинхронна обробка, MapReduce, багатопотоковість).

## Встановлення

Потрібен Python 3.13 і [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

Залежності: `aiofiles`, `aiopath`, `matplotlib`, `requests`.

Без uv: `pip install aiofiles aiopath matplotlib requests` і далі
`python` замість `uv run python`.

## Завдання 1: асинхронне сортування файлів

`task1_sort.py` рекурсивно читає всі файли у вихідній папці й асинхронно
копіює їх у цільову папку, розкладаючи по підпапках за розширенням.

```bash
uv run python task1_sort.py <source> <output>
```

| Аргумент | Опис |
|---|---|
| `source` | вихідна папка, з якої читаються файли |
| `output` | цільова папка для відсортованих файлів |

Приклад на тестових даних з репозиторію:

```bash
uv run python task1_sort.py source output
```

```
output/
├── csv/data.csv
├── jpg/photo.jpg, Copy(1)_photo.jpg, ...
├── mp3/song.mp3
├── no_extension/Makefile
├── pdf/report.pdf
├── png/beach.png
└── txt/notes.txt, readme.txt, report.txt
```

Особливості:

- **Асинхронність:** `read_folder` обходить підпапки та копіює файли
  паралельно через `asyncio.gather`; файли читаються й записуються
  частинами по 64 КБ (`aiofiles`, `aiopath`).
- **Розширення:** назва підпапки — розширення в нижньому регістрі
  (`JPG` → `jpg`); файли без розширення потрапляють у `no_extension`.
- **Однакові назви:** файл не перезаписується, а отримує префікс
  `Copy(n)_`. Перевірка атомарна (режим `xb`), тож паралельні копії
  не конфліктують.
- **Перевірки:** вихідна папка має існувати, а цільова не може бути
  всередині неї (інакше скрипт копіював би власні результати).
- **Помилки:** логуються через `logging`; збій одного файлу не зупиняє
  решту.
- Неправильні аргументи — виводиться повна довідка.

## Завдання 2: частота слів за допомогою MapReduce

`task2_word_freq.py` завантажує текст за URL, рахує частоту слів за
парадигмою MapReduce у кількох потоках і будує графік топ-слів.

```bash
uv run python task2_word_freq.py <url> [--top N] [--workers N] [--save FILE]
```

| Аргумент | Опис | За замовчуванням |
|---|---|---|
| `url` | адреса текстової або HTML-сторінки | — (обов'язковий) |
| `--top` | скільки найчастіших слів показати | `10` |
| `--workers` | кількість потоків | `4` |
| `--save` | зберегти графік у файл замість показу у вікні | — |

Запуск без аргументів виводить довідку.

Приклад:

```bash
uv run python task2_word_freq.py "https://zakon.rada.gov.ua/laws/show/254%D0%BA/96-%D0%B2%D1%80/print" --top 10
```

Як це працює:

1. **Завантаження** — `requests`; якщо сторінка HTML, з неї витягується
   лише текст (без скриптів, стилів, навігації та службових елементів
   Вікіпедії на кшталт «[редагувати]»).
2. **Розбиття на слова** — нижній регістр, лише літери будь-якого
   алфавіту, апострофи всередині слова зберігаються (`ім’я`, `don't`).
3. **Map** — список слів ділиться на частини за кількістю потоків;
   кожен потік (`ThreadPoolExecutor`) видає пари `(слово, 1)`.
4. **Shuffle** — пари групуються за словом.
5. **Reduce** — значення для кожного слова сумуються в пулі потоків.
6. **Візуалізація** — `visualize_top_words` малює горизонтальну
   стовпчикову діаграму (`matplotlib`), найчастіше слово зверху.

Службові слова (`і`, `в`, `та`…) не відфільтровуються — так само, як у
прикладі з умови завдання.
